A standard conformal prediction procedure starts from a supervised dataset, i.e., data with labels. We denote the calibration dataset by $\mathcal D = \{(X_i, Y_i)\}_{i=1}^{n} \in (\mathcal X \times \mathcal Y)^n$, kept separate from the training data used to fit the model, and the new target test point by $X_{\text{new}}$. Given a black-box model $\hat f$, we also start from <mark>some heuristic notion of uncertainty, which we call the **score function**</mark>. For example, the score can simply be the softmax score of a classification model, or the residual if we are doing regression.

For a target coverage level $1-\alpha$, the general conformal prediction algorithm is:[^split]

<TheoremBox>

1. **Compute the scores.** $S = \{ s(X_i, Y_i) \}_{i=1}^{n}$.
2. **Compute the quantile.** $\hat q = \mathrm{Quantile}\big(S;\ \lceil (n+1)(1-\alpha) \rceil / n\big)$.
3. **Return the prediction set.** $\mathcal C(X_{\text{new}}) = \{ y \in \mathcal Y : s(X_{\text{new}}, y) \le \hat q \}$.

</TheoremBox>

For example, consider the **Adaptive Prediction Sets** (APS) algorithm, which is best known for the discrete case, i.e., $\mathcal Y = \{1, \dots, K\}$. Here, we set the score function as

$$
s(x, y) = \sum_{k=1}^{K} \hat\pi_k(x)\, \mathbf{1}\{\hat\pi_k(x) \ge \hat\pi_y(x)\},
$$

where $\hat\pi_k(x)$ is the softmax output of $\hat f$ for class $k$, and $y \in \mathcal Y$ denotes the true label of $x$. In other words, the score function indicates how difficult it is, for a given input, to guess its label correctly.[^adaptive] The full method is described below.
